## 7. Dead ends already tried

- Widening `providerKindSchema` itself to include native-local: ripples through ~20 external-only call sites (LIVE_ROUTES, discovery, roster). Use `runtimeKindSchema` for worker identity only.
- Storing check output in receipts/evidence: violates the "check output is not evidence" invariant (test `fails checks without retaining their output as evidence`).

## 8. Decisions, rationale, and invariants

- Native-local live route admits only loopback HTTP and an explicit model; there is no native bypass because every action goes through XVANT's registry.
- Native catalog: `file.read`, `file.apply_patch`, `repo.search`, `git.inspect`, `test.run` (registered checks). `command.run` is excluded (needs per-action approval).
- Stub models (`ScriptedProvider`, fake endpoint) are always `offline` classification.
- Known terminal outcomes release reservations after the runner awaited the process; unknown never does.
- Tool receipt events never contain result bodies.
