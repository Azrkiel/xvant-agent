## 5. Decisions and invariants added

- Interrupts are host admissions, never scenario side effects; admission commits
  before the frame; admitted interrupts can never record `completed`.
- Native failure classification reads pinned code labels only, never message
  text; account-scoped failures (`AUTH_REQUIRED`, `QUOTA_BLOCKED`) block the
  whole `quotaGroupId` until a trusted `clearBlock`; reconciliation does not clear.
- The OpenCode endpoint secret never touches disk or the journal (digest only);
  unauthenticated 401 is required before use; only `http://127.0.0.1:<port>`.
- Native sessions are unique per runtime+host (reservation key), not globally.

## 6. Dead ends / gotchas

- Node `res.writeHead` does not flush SSE headers; the fixture must
  `flushHeaders()` or the client waits forever.
- A request socket idle timeout also kills quiet SSE streams; clear it once
  headers arrive (owned process deadline bounds the run).
- The fixed peers mint one created-session ID per runtime; a second create in the
  same Store collides (correctly refused).
- The Codex channel can mark a connection `unknown` before the controller sees
  the error; `recordFailure` therefore accepts `open` or `unknown`.
