## Decisions, rationale, and invariants

- Registry is an offline in-memory contract, not integrated with the durable
  controller. The controller still runs only the Phase 2 simulator.
- Session uniqueness is runtime + host + native session, independent of endpoint
  labels. Native IDs are opaque strings, never filesystem paths.
- One active binding per session. Terminal messages/cancel requests never release
  it; a trusted controller confirms stopped/not-started and completes verification.
- Imported/attached modes cannot mutate. No approval handler exists yet.
- `negotiate` is advisory, not an authority boundary. Before consuming it live,
  implement persisted, dated, source-bound host evidence and freshness validation.
- CLI accepts only offline or inventory-only modes. Live/read-only flags fail
  closed. Inventory executes native executables with fixed `--version`, no shell,
  five-second timeout and 16 KiB output cap. Raw diagnostics are not printed.
- Claude fixture invocation IDs are host-owned; OpenCode fixtures correlate
  assistant message IDs. Neither is claimed to be a native provider turn ID.
- Native error translation, account quota admission, approvals, streaming,
  cancellation transports and crash recovery are not implemented by these fixtures.
