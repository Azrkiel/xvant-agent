## Decisions, rationale, and invariants

- Check controller ownership before migrations in the same immediate transaction. A rejected second controller must leave the schema unchanged.
- Hold workspace/session/worker reservations through verification. Unknown worker OR verifier shutdown retains reservations until trusted reconciliation attests `not_started` or `stopped`.
- Controller lifecycle owns lease renewal even while idle. Global stop latches admission; startup failure stops renewal and closes the database.
- Command keys are scoped by project and kind. Same payload returns the original result; changed payload conflicts.
- Artifact objects are immutable and written before database references. Snapshot copies all retained objects, a safe superset, and requires every database reference in the manifest.
- Snapshot validation checks types, keys, nullability and foreign keys, not just column names. Integrity check alone does not prove a usable application schema.
- Restore only to a new directory. Preserve captured ownership expiry; immediate reopen may require waiting the remaining default 30-second TTL. Never overwrite or downgrade a live database.
- Store data belongs on local nonsynchronized storage. Network/sync-backed database durability is not qualified.
