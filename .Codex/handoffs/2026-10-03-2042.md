- MPL-2.0 is allowed for development-only dependencies (my call; operator has not objected).
- The benchmark counts for a release only with an XVANT-orchestrated configuration and a baseline in it.
- **Source hash includes `plan.md`, `docs/plans` and `.Codex`.** Any commit that touches them makes the offline gate receipt stale. Before a release: update docs, run `npm run gate -- --phase 10 --offline`, then commit only `docs/evidence`.
- A gate fails if any file in the checkout changes while it runs. Other agents use their own worktree.
- Unknown outcomes are never retried automatically; quota or auth stops are recorded as incomplete, never as success.
